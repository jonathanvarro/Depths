# Exploration mist

Depths #247. Three low world-registered transparent sheets, using the existing
authored ambient-v1/fog-strip.png alpha. No new generated bitmap or external
source. Shader motion is an explicit phase, so set_motion(false) is exact.

Ambience owns placement, quiet states, light bands and effects preference.
This scene changes no visibility/encounter/navigation rules. Standalone API
and native/browser review are in docs/traps-sites-and-mist-3d.md.
