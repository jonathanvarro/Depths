# Ambient pixel effects

Use `catalog.json` for frame size/count, columns, speed, blend and conditions.
Every SpriteFrames animation is named `loop`, with nearest filtering.

These are cosmetic assets. Eyes and the shadow are unrelated to real enemies.
Local torch/fungus glow must not change carried light or nerves. The darkness
atlas has one strong loop; fade it for the three intensities, below the HUD.

Full handoff, source authoring and the pause/step inspector:
[cave-dressing-assets.md](../../../docs/cave-dressing-assets.md).
