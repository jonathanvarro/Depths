# Fungal Hollows / Grove concepts

Seven selected plates, plus superseded boss v1 for comparison. The owner
accepted the set and the corrected masculine Flower Knight v2. Numbering follows
the owner's eight references; **#4 deliberately has no concept image** and
remains a regional reward-armour idea in the handoff.

Open `inspector.html` for the complete set. `generation.json` records every
exact prompt, reference/edit-target role, unchanged generated source path,
dimensions, SHA-256 and approval. Original user references are not vendored.
`.gdignore` keeps this review-only library out of live Godot imports.

Source images were generated with the built-in image tool and copied without
pixel edits, crops or recompression. Labels are provisional. No 3D models,
runtime skins, statistics, items, encounters or recruitment flow are delivered.
Full direction: `docs/fungal-hollows-grove-concepts.md`, issue #306.

The separately explored optional character was rejected and is excluded.
