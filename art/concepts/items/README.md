# Item inventory art — plain knife draft

`plain-knife-v1.png` is a draft inventory visual for the proposed basic knife (#28). The plain iron blade and riveted wooden handle fit the starting cave's apprentice-made, inexpensive equipment. It uses muted iron/brown colours, warm upper-left highlights and a diagonal silhouette against genuine transparency.

- Created 2026-10-17 with the built-in image-generation tool.
- Original output copied unmodified into the project; original retained.
- PNG, 1254 x 1254, RGBA; decoded and alpha channel checked (range 0–255).
- Visually reviewed for simple construction, full-item composition, silhouette and the dark pixel-art direction.
- Concept only: not a 64 x 64 production icon, a hand-cleaned pixel master or an implemented inventory item. The generated image has more surface detail than a small slot may retain; pixel-scale cleanup, alpha-edge cleanup and testing over actual dark/light selection backgrounds are still needed. The transparent margin contains faint alpha pixels, so do not assume an automatic nontransparent crop will give the intended bounds.
- A 64 x 64 slot is a readability target proposed for this draft, not an approved item-art resolution standard. Keep the source and prepare separate exports only after reviewing the direction.
- This asset does not approve the economy report's knife stats/price, determine Mara's starting equipment, add a durability mechanic or introduce a knife with random defects.

See [starter equipment research](../../../docs/starter-cave-economy-research.md) and [the campsite design](../../../docs/campsite-design.md).

## Generation prompt

Use case: stylized-concept. Asset type: one plain starter knife inventory icon draft for Depths, a dark medieval first-person dungeon crawler on Windows and landscape iPhone. Primary request: a humble, usable village-apprentice-made utility knife, ordinary starter equipment, NOT a fantasy sword or ornate dagger. One isolated whole knife, short broad single-edged iron blade with a straightforward pointed tip, subtle hammer marks and slight tarnish, a clean serviceable cutting edge, plain dark wooden handle with two small iron rivets, no elaborate guard. Three-quarter inventory view, diagonal from lower-left handle to upper-right blade tip, centered and filling about 78 percent of a square canvas with generous clean transparent padding. Distinct readable silhouette and bold sparse pixel clusters that would remain understandable in a 64x64 inventory slot. Deliberate coarse pixel-art aesthetic with crisp stepped edges, limited charcoal/iron gray/worn brown/dirty parchment highlight palette, restrained upper-left warm lantern illumination, deep simple shadow on underside. Simple game asset illustration, no photorealism, no painterly brushwork, no smooth gradients, no excessive microdetail. No magic, jewels, gold, runes, blood, broken blade, display surface, hand, person, text, item card, slot border, UI, backdrop or cast shadow outside the object. Actual transparent background, no checkerboard painted into image. This is an inventory art direction draft, not a production-resolution commitment.
