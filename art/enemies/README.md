# Enemy art

**Use [cave-simple-v1](cave-simple-v1/README.md) for combat.** It contains the current simplified rat, spider and goblin sets: 128px transparent idle/attack/hurt sprites with SpriteFrames and compatible scenes. The three EnemyType definitions point to them.

[Art direction](../../docs/enemy-art-direction.md) sets the shared production rules. `cave-v1` retains the earlier detailed exploration set; `style-study-v1` preserves the initial goblin comparison.
