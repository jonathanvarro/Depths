# Rat pilot

Derived from **Rat by br-n518**, CC0:
https://opengameart.org/content/rat-0.
Original archives, declaration and pinned hashes: `art/third-party/oga-rat-v1`.

Depths changes: 128px muted 32-colour hide, fixed metric wrapper (0.48 source
scale, Godot +Z front), a hurt action based on the idle endpoint, sampled
internal root-height corrections and an explicit closing frame on walk/run.
Original mesh topology, UVs, weights and 21-bone hierarchy are retained.
No third-party character-library or Mixamo content is used.

One 270-triangle surface. Shared cave grain is the project's existing
`art/third-party/kaykit-dungeon-remastered/grain-floor1.png` treatment.
This is a review candidate; no EnemyType resource is replaced.
