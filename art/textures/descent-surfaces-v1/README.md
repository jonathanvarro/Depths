# Matching descent floors and ceilings · #139

Twelve opaque 128px textures/materials for the six existing deeper wall families.
Each uses its wall's exact 32-colour palette, nearest repeat sampling and roughness 1.
[Catalogue](catalog.json) · [inspector](../../concepts/descent-finish-v1/inspector.html) ·
[handoff](../../../docs/descent-surfaces-and-dressing.md).

Assign `<family>-floor.tres` and `<family>-ceiling.tres` to the corresponding
future EnvironmentTheme slots. Existing walls and live themes are unchanged.
Family names/later floor numbers are proposals. Sources/prompts are preserved
in `art/source/descent-surfaces-v1`. Rebuild/check instructions and the existing
wall UV density limitation are documented in the handoff.
