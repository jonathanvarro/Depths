# Recruit roster v1

Combined nine-face mapping: catalog.json (three Warden, Scout and Brawler).
The two original faces stay in recruit-kit-v1; seven new folders here.
Every layer is 192x192 RGBA, origin (0,0). Reuse the original shared body
and jerkin; do not trim components. Neutral sets blink/talk; worried and
exhausted are static. Conditions: blood, dirt, bandage, pallor.

Open preview.tscn with F6 for the isolated nine-face review.
See docs/recruit-roster.md for stable paths, optional separate lighting,
editable sources, scope and validation. Live recruit wiring is separate.
