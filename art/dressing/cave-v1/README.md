# Cave dressing

Use `catalog.json` for textures, scenes, mounts, pivots, metre scale, opacity
and source provenance. All assets are cosmetic. Placement and exclusions
belong to the game, not these scenes.

The lit wall torch is `goblin-torch-lit.tscn`; its unlit version is
`goblin-torch-base.tscn`. Its local light is mood only. The separate dead
mining sconce remains unlit. Timber parts retain a common source registration.

Full handoff, previews and rebuilding:
[cave-dressing-assets.md](../../../docs/cave-dressing-assets.md).
