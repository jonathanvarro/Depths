# Bones and remains

Instantiate scattered-bones.tscn or small-remains.tscn for loose dungeon
dressing. fallen-skeleton.tscn and seated-skeleton.tscn are complete character
studies with the source pack's oversized heads.

The recipes assign the appropriate shared material and cave grain. When
placing an individual loose GLB directly, use material-halloween.tres.
Every model is floor-centred and uses metre units.

Sources, licence verification and sizes are documented in
docs/bone-decor-library.md. Original CC0 files are retained under
art/third-party/kaykit-bones-v1.
