# Area-route glyphs (#302)

Six original code-native SVGs: Cavern, Fungal Hollows, Damp Caves, and each area's transition version. Same ivory stroke language as `art/ui/expedition-v1/map/deep-water.svg`: 32px viewBox, 2.5px strokes, transparent and tintable. No image generation or third-party artwork.

Cave arch / fungal cap / paired drops match the raised chalk geometry on the corresponding passage signs. The arrow means a transition, not numeric depth. Canonical map and prompt names come from catalogued area/destination metadata; these assets do not create graph links or reveal unexplored exits. Native 16/24/32px display checks and screenshot are in the passage gallery. Future area glyphs remain separate production work.
