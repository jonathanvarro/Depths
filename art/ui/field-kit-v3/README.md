# Field kit v3

Full fitted backpack, worn quest-book spine and original generic equipment
diagram for #290. Live use and review:
`docs/field-kit-silhouette-and-menu.md`.

PNG generation mode: built-in imagegen. Exact prompts, original output names,
dimensions, hashes and runtime registration are in `generation-manifest.json`.
Generated pixels are preserved unchanged. The existing project backpack was
the material/style reference. `body.svg` is an original code-authored vector.
Chrome comes from `art/ui/reliquary-brass-v1`, not these drawings.
