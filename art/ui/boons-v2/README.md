# Boon and bane symbols (#138)

Eleven original 32px SVG-authored glyphs, rasterized losslessly by Godot.
Used through `data/boons/*.tres` at the existing 14px party-card size. Shapes
remain distinct in greyscale; colour and the small circle/triangle category
marks are secondary cues. Existing generic boons-v1 fallbacks remain intact.

Sources: `art/source/field-kit-v1/glyphs`. Catalogue:
`art/items/field-kit-v1/catalog.json`. Handoff: `docs/field-kit-art.md`.
Review: `art/concepts/field-kit-v1/inspector.html`.
