# Treasure icons v1

Fourteen 64x64 RGBA icons, clear margins, nearest display. catalog.json
maps stable IDs to labels, 128px illustrations and available world scenes.
Rough coins, leather/cloth bags, chest states, jewelry, gems and silver cup.
No prices, currency thresholds, item effects or loot quantities assigned.

See docs/treasure-art.md for integration, provenance and checks. The chest
icons describe containers and do not imply a carryable chest item.
