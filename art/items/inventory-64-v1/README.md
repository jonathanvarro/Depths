# Inventory exports

Transparent 64px, nearest, at least 4px padding, up to 32 colours. `catalog.json` maps sixteen exports and seven live icon assignments. `gold-coin.svg` is a separate 20px UI glyph.

See [production/rebuild/validation handoff](../../../docs/playable-art-pass.md) and [live native/40px comparison](../../concepts/inventory-64-v1/live-library-dark.png). Source masters and exact ImageGen prompts are preserved under `art/source/inventory-64-v1`.
