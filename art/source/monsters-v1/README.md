# Immutable monster source art · #141

Twenty-three built-in ImageGen originals copied byte-exact: eleven identity
studies, eleven pose boards and one correction to the captain's duplicated horn.
[generation.json](generation.json) and `records/` retain exact prompts, reference
roles/paths, original generated locations and hashes. Only the fixed rally cell
is used from the correction; other captain poses retain their earlier source.

Original native SVG marks live in `glyphs/`; native cloud/light FX are authored
in `tools/art/build_monster_effects.py`. Source preservation and registration
recipe: [full handoff](../../../docs/new-monster-art.md).
