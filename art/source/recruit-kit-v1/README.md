# Recruit portrait sources · v1

Nine original built-in image_gen.imagegen outputs plus four repeated
reference boards, retained for exact registration and future revision.
generation-manifest.json preserves prompts, flags and source paths.
The repeated boards were generated by copying each unchanged master into
512px square cells: 3x2 for face animation, 2x2 for conditions/light.

warden-a.ora and scout-a.ora are editable full-canvas OpenRaster stacks:
shared body/outfit, individual head, neutral features, and hidden
expression/animation/condition/light layers. Do not enable multiple eye
or mouth replacements simultaneously. Raw light passes need controlled
blend strengths; see docs/recruit-portrait-kit.md.

Only the upper-left light pair is delivered. Mirrored-right source
studies remain source history, not registered runtime art.
tools/art/build_recruit_portraits.py rebuilds native exports, resources,
stacks, hashes and review boards. Source/review folders are ignored by
Godot import, and the existing export preset excludes art/source.
