# Campsite generated masters

Ten original built-in image_gen.imagegen outputs, retained unmodified.
generation-manifest.json records exact prompts, reference paths and
generated-file provenance. Merchant progression v2 and the existing
campfire base were references; both originals remain unchanged.

tools/art/build_campsite_art.py exports the native runtime textures into
art/camp/cave-camp-v1. Source masters are excluded from Godot import and
the existing Windows export. See docs/campsite-art.md for scope and usage.
