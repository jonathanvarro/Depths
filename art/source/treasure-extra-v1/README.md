# Additional valuables sources v1

Eight unmodified built-in image_gen.imagegen outputs. Exact prompts,
transparency flags, generated paths and reference roles are retained in
generation-manifest.json. Each item was generated separately; the original
silver goblet, signet ring and coin purse are style references, not edit
targets. No source or prior asset is overwritten.

tools/art/build_treasure_extra_art.py reuses the original treasure export
helpers for deterministic alpha/palette/nearest-size exports and reviews.
Sources and reviews have .gdignore; export excludes art/source and tools.
