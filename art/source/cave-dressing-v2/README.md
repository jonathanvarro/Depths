# Immutable ImageGen dressing masters and native ornaments

Sixteen built-in ImageGen originals, including the retained rejected blunt-spike
candidate; fifteen selected subjects. [generation.json](generation.json) records
full prompts, reference roles/paths, original output paths and hashes.
`native/` retains original SVG scratch/inscription/seal/ink drawings and their
Godot rasterizations. Glow contributions are native pixel FX in the exporter.
No API/CLI generation was used.

[reused-inputs.json](reused-inputs.json) pins all existing walls, themes,
level/placement code, mushrooms, wall fungus and drip frames used in review.
