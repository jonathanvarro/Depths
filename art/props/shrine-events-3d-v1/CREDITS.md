# Defiled shrine, fouled well and buried cache

Authored geometry for Depths using `tools/rat_landmarks/build_landmarks.py`
and the existing authored mesh helpers in `tools/mine_props/build_models.py`.
The shrine reuses the project's carved miner and niche geometry, without
importing the earlier third-party candles. Masonry, bucket, rope, well inset,
crate, rubble and royal stamp are authored geometry. No new downloaded mesh
is used for these landmarks.

Visual references: the project's existing `art/props/shrine-events-v1`
paintings and current event clues, retained unchanged. Shared 25-colour
palette and existing world-space cave grain. No generated painting, private
character model or Mixamo data is included.

See `docs/rat-and-shrine-landmarks-3d.md` for mounts and state limitations.
